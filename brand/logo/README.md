## ফন্ট

Outfit: "HSC" ExtraBold 800, "STUDY" SemiBold 600, অক্ষরের ফাঁক 0.04em।
SVG ফাইলে লেখাগুলো path করা, তাই কোনো কম্পিউটারে ফন্ট ইনস্টল করতে হয় না।

## নিয়ম (সংক্ষেপে)

- চারপাশে কমপক্ষে আইকনের উচ্চতার অর্ধেক ফাঁকা জায়গা।
- ন্যূনতম মাপ: পুরো লোগো ১২০px চওড়া (ছাপায় ৩০ মিমি), শুধু আইকন ১৬px।
- টেনে লম্বা বা চ্যাপ্টা করবেন না, রং বদলাবেন না, ঘোরাবেন না, ছায়া বা ইফেক্ট দেবেন না, ব্যস্ত ছবির উপর বসাবেন না।
