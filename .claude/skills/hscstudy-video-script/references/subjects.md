# বিষয়ভিত্তিক নিয়ম (সব HSC বিষয়)

সব বিষয়ে একই নিয়ম: **তথ্য শুধু ইউজারের দেওয়া পাঠ্যবইয়ের পাতা থেকে।** বই না থাকলে আগে পাতা চাইবে।
প্রতিটা সংখ্যা, হিসাব, সমীকরণ কোড চালিয়ে মিলিয়ে নেবে।

## Series label
স্ক্রিনে আর থাম্বনেইলে: `{বিষয়ের ছোট নাম} · {অংশের নাম}`। উদাহরণ:
- ICT · অধ্যায় ৩
- পদার্থবিজ্ঞান ১ম পত্র · অধ্যায় ২
- বাংলা ১ম পত্র · কবিতা (অধ্যায় নম্বর না থাকলে গদ্য/কবিতা/সহপাঠ বা রচনার নাম)
- হিসাববিজ্ঞান ২য় পত্র · অধ্যায় ৪

## গণিত-ভিত্তিক বিষয় (উচ্চতর গণিত, পদার্থবিজ্ঞান, রসায়নের হিসাব, ICT সংখ্যা পদ্ধতি, হিসাববিজ্ঞান, ফিন্যান্স, পরিসংখ্যান)
- Script-এ (TTS-এর জন্য) সংখ্যা ও চিহ্ন কথায়: "এক শূন্য এক এক", "এক্স স্কয়ার", "দুই বাই তিন", "সমান", "যোগ", "শতাংশ"।
- Screen-এ পাঠ্যবইয়ের মতো গাণিতিক রূপ: (1011)₂, x² + 2x + 1 = 0, ⅔, F = ma, 25%। ভগ্নাংশ, ঘাত, subscript ঠিকঠাক।
- message.txt-এ **"স্ক্রিনে গাণিতিক রূপ"** তালিকা দেবে: কোন বাক্যের কোন রূপ।
- প্রতিটা হিসাব Python/JS দিয়ে চালিয়ে মিলিয়ে নেবে; কুইজের উত্তরও।
- একক (SI unit) সবসময় দেখাবে: m s⁻², J, mol।
- Visual: ধাপে ধাপে হিসাব (প্রতিটা ধাপ আলাদা লাইনে আসে), গ্রাফ, জ্যামিতিক চিত্র নিজে আঁকা।

## রসায়ন
- সংকেত ও সমীকরণ: H₂SO₄, 2H₂ + O₂ → 2H₂O। সমীকরণ সমতা (balanced) কোডে যাচাই করবে।
- TTS: "এইচ টু এস ও ফোর" বা বাংলা নাম ("সালফিউরিক এসিড") — বইয়ে যেভাবে পড়ানো হয়।
- Visual: অণুর গঠন সরল বল-স্টিক, বিক্রিয়ার তীর।

## জীববিজ্ঞান
- বৈজ্ঞানিক নাম *ইটালিকে*, বানান হুবহু বই থেকে।
- চিত্র নিজে আঁকা সরল flat diagram (কোষ, অঙ্গ), লেবেলসহ; বইয়ের ছবি কপি নয়।

## ICT
- Code (HTML, Python, SQL): Fira Code-এ, syntax হুবহু; যে code দেখাবে সেটা আসলে চালিয়ে দেখবে কাজ করে কিনা।
- ২০২৬-২৭ সংস্করণে অধ্যায় ৫ পুরোপুরি **Python** (C নয়) আর অধ্যায় ৬-এর SQL অনুশীলন **SQLite**-এ। পুরোনো C-এর উদাহরণ দেবে না।
- বইয়ের পরিভাষা ও উদাহরণ ব্যবহার করবে: ট্রেস টেবিল, IPO মডেল, লুপ প্যাটার্ন, ফাংশন কন্ট্রাক্ট; বুলিয়ান পূরক screen-এ overline দিয়ে (x̄)।
- বিস্তারিত অনুচ্ছেদ-নোট: repo-র `docs/textbook-notes/ict-2026-27.md`।
- Visual: নেটওয়ার্ক, টপোলজি, লজিক গেট, ঘরের মান — নোড-রেখার ব্র্যান্ড motif এখানে দারুণ মানায়।

## বাংলা ১ম/২য় পত্র
- সাহিত্য: উদ্ধৃতি হুবহু বইয়ের পাঠ থেকে, ছোট অংশ; লেখক/কবির তথ্য শুধু বইয়ের "লেখক পরিচিতি" থেকে।
- উদ্ধৃতি screen-এ Noto Serif Bengali-তে, উদ্ধৃতি চিহ্নসহ।
- সুর: শ্রদ্ধাশীল, আবেগী কিন্তু বাড়াবাড়ি নয়। লেখকের ছবি বানাবে না (বাস্তব মানুষের ছবি নয়)।
- ব্যাকরণ (২য় পত্র): নিয়ম → উদাহরণ → ব্যতিক্রম; উদাহরণ বই থেকে।

## ইংরেজি ১ম/২য় পত্র
- ব্যাখ্যা বাংলায়, ইংরেজি বাক্য/শব্দ ইংরেজিতে; screen-এ ইংরেজি বাক্য হুবহু।
- Grammar: rule → example → common mistake; উচ্চারণ যেখানে দরকার সেখানে বাংলা হরফে নয়, ইংরেজিতেই।

## ব্যবসায় শিক্ষা (হিসাববিজ্ঞান, ব্যবসায় সংগঠন, ফিন্যান্স, উৎপাদন ব্যবস্থাপনা)
- জাবেদা/খতিয়ান/টেবিল screen-এ সারণি আকারে; যোগফল কোডে মিলিয়ে নেবে (ডেবিট = ক্রেডিট)।
- উদাহরণ বাংলাদেশি ব্যবসা থেকে (দোকান, মুদি, গার্মেন্টস) — কিন্তু নির্দিষ্ট কোম্পানির নাম/লোগো নয়।

## মানবিক (ইতিহাস, ইসলামের ইতিহাস, পৌরনীতি, অর্থনীতি, ভূগোল, সমাজবিজ্ঞান, যুক্তিবিদ্যা)
- সাল, নাম, সংখ্যা শুধু বই থেকে; কোনো রাজনৈতিক মত বা পক্ষ নয়, নিরপেক্ষ ভাষা।
- Visual: timeline, মানচিত্রের সরল রূপরেখা (নিজে আঁকা), cause → effect চিত্র।
- বাস্তব ঐতিহাসিক ব্যক্তির ছবি বানাবে না; নাম আর সময়রেখা দিয়ে দেখাবে।

## সব বিষয়ে পরীক্ষার টিপস

- "এটা প্রতি বছর বোর্ডে আসে", "১০০% কমন", "পরীক্ষায় আসবেই" জাতীয় দাবি করবে না, যদি না ইউজার প্রমাণ (প্রশ্নের তালিকা) দেয়।
