## অধ্যায় ২ — কমিউনিকেশন সিস্টেমস ও নেটওয়ার্কিং (book 49–89)
শিখনফল: communication system; data communication; data transmission method/mode; মাধ্যম তুলনা; অপটিক্যাল ফাইবার; ওয়্যারলেস; মোবাইল প্রজন্ম; নেটওয়ার্ক ধারণা, গুরুত্ব, ধরন, টপোলজি; ক্লাউড কম্পিউটিং ও সুবিধা।
- ২.১ কমিউনিকেশন সিস্টেম — ২.১.১ ধারণা, ২.১.২ ডেটা কমিউনিকেশন (উৎস → ইনপুট ট্রান্সডিউসার → ট্রান্সমিটার → মিডিয়াম(+নয়েজ) → রিসিভার → আউটপুট ট্রান্সডিউসার → গন্তব্য)
  - উপাদানের উদাহরণ ৫টি; ২.১.৩ ব্যান্ডউইথ (bps, kbps, Mbps, Gbps; 8 bit = 1 byte)
  - ২.১.৪ ডেটা ট্রান্সমিশন মেথড: প্যারালাল / সিরিয়াল (USB); bit synchronization; সিরিয়াল → অ্যাসিনক্রোনাস (start/stop bit, keyboard), সিনক্রোনাস (block/frame, header/trailer), আইসোক্রোনাস (real-time audio/video)
  - **ডেটা ট্রান্সমিশন দক্ষতা = প্রকৃত ডেটা / মোট ডেটা × ১০০%** — worked math: 5 KB async: 40000 bit + 15000 extra (3 bit per 8) → 72.72%; with 1 start + 1 stop bit → 80%. (calculation-type questions!)
  - ২.১.৫ ডেটা ট্রান্সমিশন মোড (প্রবাহের দিক): সিমপ্লেক্স, হাফ-ডুপ্লেক্স, ফুল-ডুপ্লেক্স; ডেটা ডেলিভারি মোড: ইউনিকাস্ট, ব্রডকাস্ট, মাল্টিকাস্ট
- ২.২ ডেটা কমিউনিকেশন মাধ্যম — Guided (wire) / Unguided (wireless) diagram with frequency ranges:

  3G 2001–2008 (NTT DoCoMo; packet switching; >2 Mbps; HSPA, WCDMA, 3GPP, UMTS; FOMA), 4G 2009–2020 (IP-based; LTE; 100 Mbps mobile / 1 Gbps fixed; VoIP; 50× faster than 3G), 5G 2020– (WWWW; 5G NR, RAT, MIMO; 4K; "আমাদের দেশেও 5G চালু হতে যাচ্ছে")
- ২.৫ কম্পিউটার নেটওয়ার্কিং — ২.৫.১ ধারণা, ২.৫.২ উদ্দেশ্য (information / software / hardware resource sharing)
  - ২.৫.৩ প্রকারভেদ: ভৌগোলিক — PAN (≤10 m), LAN (≤1 km; star/bus/tree/ring), CAN (1–5 km; Googleplex), MAN (~50 km; WMAN), WAN (internet); সার্ভিস/নিয়ন্ত্রণ — peer-to-peer, client-server (centralized / distributed), hybrid; মালিকানা — public, private

  - ২.৫.৫ নেটওয়ার্কের কাজ (৯টি)

  - ২.৫.৮ **নেটওয়ার্কে লেয়ারের ধারণা (NEW):** why layers — complexity reduction, standardization, easy troubleshooting, modularity …
    OSI model (ISO), 7 layers with job/device/unit/protocol (NEW, very examinable):
    L7 Application (Chrome, WhatsApp; HTTP, HTTPS, FTP, SMTP, DNS) · L6 Presentation ("অনুবাদক"; formatting, encryption, compression; JPG, MP4, GIF) ·
    L5 Session (checkpoint) · L4 Transport (segments; TCP reliable, UDP fast) · L3 Network (routing, IP address; router; packet) ·
