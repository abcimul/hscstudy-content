ফরম্যাট (মালিকের সিদ্ধান্ত, ২০২৬-১১-০৪): Reels/Shorts, 9:16, ৩০–৪৫ সেকেন্ড। প্রতি Reel-এ **একটা ট্রিক**, যেটা
শিক্ষার্থী হাতে-কলমে করে দেখতে পারে আর এক লাইনে মনে রাখতে পারে। সিরিজের নাম "ICT ট্রিক", নম্বরসহ

## বিস্তারিত

### ১. এক হাতে ৩১ (৩.২.১, পৃষ্ঠা ৯২–৯৪)
- ট্রিক: বুড়ো আঙুল ১, তারপর প্রতি আঙুলে দ্বিগুণ: ২, ৪, ৮, কড়ে আঙুল ১৬। তোলা আঙুল = 1, ভাঁজ = 0; তোলা আঙুলের মান যোগ।
- উদাহরণ: ভি চিহ্ন = 2 + 4 = 6 = (110)₂। সব আঙুল = 31 = (11111)₂।
- কুইজ: শুধু বুড়ো আঙুল আর কড়ে আঙুল → 1 + 16 = 17 = (10001)₂
- সতর্কতা: শুধু মাঝের আঙুল তোলা (৪) কখনো দেখাবে না।

### ২. জোড় না বিজোড়? শেষ বিট দেখো ⚑ (LSB, ৩.২.১, পৃষ্ঠা ৯৩)
- ট্রিক: LSB 0 হলে জোড়, 1 হলে বিজোড়, কারণ শেষ ঘর ছাড়া সব ঘরের মান জোড়। রূপান্তরের উত্তর চেক করতেও কাজে লাগে।
- উদাহরণ: (1011)₂ = 11, বিজোড়।
- আলাদা রাখা আইডিয়া (এক Reel = এক ট্রিক): শেষে একটা 0 বসালে মান দ্বিগুণ, (10110)₂ = 22; দশমিকে শেষে 0 বসালে দশ গুণ, একই খেলা।
- কুইজ: (100101)₂ জোড় না বিজোড়? → বিজোড় (37)

### ৩. ভাগ ছাড়াই দশমিক থেকে বাইনারি (৩.২.২, পৃষ্ঠা ৯৫: বইয়ের প্রথম পদ্ধতিই ২-এর ঘাতের যোগফল)
- ট্রিক: ১-২-৪-৮-১৬-৩২-৬৪ সিঁড়ির সবচেয়ে বড় যে ধাপ ঢোকে, সেটা নাও; বাকিটা দিয়ে আবার।
- উদাহরণ (বই): 76 = 64 + 8 + 4 = (1001100)₂
- কুইজ: (52)₁₀ → (110100)₂

### ৪. ভাগে উঠো, গুণে নামো (৩.২.২, পৃষ্ঠা ৯৫–৯৬; নিয়ম বইয়ের, লাইনটা শুধু মনে রাখার জন্য)
- ট্রিক: পূর্ণ অংশে ২ দিয়ে ভাগ, ভাগশেষ **নিচ থেকে উপরে**। ভগ্নাংশে ২ দিয়ে গুণ, পূর্ণ অংশ **উপর থেকে নিচে**।
- উদাহরণ: (25.75)₁₀ = (11001.11)₂ (বইয়ের (11001.110)₂ = (25.75)₁₀-এর উল্টো দিক)
- কুইজ: (6.5)₁₀ → (110.1)₂

### ৫. ০.১ বাইনারিতে শেষই হয় না ⚑ (৩.২.২, পৃষ্ঠা ৯৬; নিয়ম বইয়ের, (0.1)₁₀ বইয়ে নেই, কোডে মেলানো: বাকি 0.2 চার ধাপ পরে ফিরে আসে)
- উদাহরণ: 0.625 → (0.101)₂, শেষ হয়। 0.1 → (0.000110011…)₂, 0011 বারবার ঘুরে আসে। বইয়ের 0.46 → (0.01110…)₂।
- টিপস: শেষ না হলে বইয়ের মতো কয়েক ঘর লিখে তিন ডট দেবে।
- কুইজ: (0.75)₁₀ → (0.11)₂ (শেষ হয়)

### ৬. অক্টালে ৩ ঘর, হেক্সে ৪ ঘর (৩.২.২)
- ট্রিক: 8 = 2³ তাই অক্টালের এক অঙ্ক = ৩ বিট (৪-২-১); 16 = 2⁴ তাই হেক্সের এক অঙ্ক = ৪ বিট (৮-৪-২-১)।
- উদাহরণ (বই): (412)₈ = (100 001 010)₂; (9F23)₁₆ = (1001 1111 0010 0011)₂
- কুইজ: (2D)₁₆ → (101101)₂

### ৭. হেক্স থেকে অক্টাল: বাইনারির সেতু (৩.২.২)
- ট্রিক: হেক্সকে ৪ বিটে ভাঙো, ডান দিক থেকে ৩ বিটে জোড়ো।
- উদাহরণ (বই): (B2F)₁₆ = 1011 0010 1111 = 101 100 101 111 = (5457)₈
- কুইজ: (3F)₁₆ → (77)₈

### ৮. অক্টালে ৮ নেই! মিটারের মতো গোনা (৩.২.১)
- ট্রিক: ঘরের শেষ অঙ্কে পৌঁছালে শূন্য হয়ে পাশের ঘরে এক যোগ (বাইক বা CNG-র মিটারের মতো)। অক্টালে 7-এর পরে 10, হেক্সে F-এর পরে 10।
- উদাহরণ: (17)₈-এর পরে (20)₈; (1F)₁₆-এর পরে (20)₁₆। বইয়ের "হেক্স 38 থেকে পরের ২৫টি সংখ্যা লেখো" এই ট্রিকেই হয়।
- কুইজ: (77)₈-এর পরের সংখ্যা? → (100)₈

### ৯. F মানে Full ⚑ (৩.২.১)
- ট্রিক: A = 10 ধরে গুনে যাও (B 11, C 12, D 13, E 14, F 15)। F = 15 = 1111, চার ঘরই ভর্তি।
- কুইজ: (C)₁₆ বাইনারিতে? → (1100)₂

### ১০. ১ + ১ = ১০ কেন? (৩.৩)
- ট্রিক: যোগফল ভিত্তির সমান বা বড় হলে ভিত্তি বিয়োগ করো, হাতে থাকে এক।
- উদাহরণ: দশমিক 7 + 5 = 12; অক্টাল (7 + 5)₈ = (14)₈; বাইনারি 1 + 1 = (10)₂। বই: 101100101 + 11001001 = 1000101110।
- কুইজ: (111)₂ + (1)₂ → (1000)₂

### ১১. ধার নিলে আসে ভিত্তি (৩.৩)
- ট্রিক: পাশের ঘর থেকে এক ধার নিলে এই ঘরে আসে ভিত্তির সমান। বাইনারিতে ধার মানে ২, তাই (10)₂ − 1 = 1।
- উদাহরণ (বই): 101100101 − 11001001 = 10011100
- কুইজ: (1000)₂ − (1)₂ → (111)₂

### ১২. ২-এর পরিপূরক এক টানে ⚑ (৩.৫)
- ট্রিক: ডান দিক থেকে প্রথম 1 পর্যন্ত যেমন আছে রাখো, তার বামের সব বিট উল্টাও। (বইয়ের "উল্টাও + ১"-এর সমান ফল।)
- উদাহরণ: +52 = 00110100 → 11001100 (= −52)। বইয়ের 10110011 → 01001101-ও মেলে।
- টিপস: খাতায় বইয়ের নিয়ম (১-এর পরিপূরক + ১) দেখাবে; ট্রিক দিয়ে মিলিয়ে নেবে।
- কুইজ: 01011000-এর ২-এর পরিপূরক? → 10101000

### ১৩. MSB-এর দাম মাইনাস ১২৮ ⚑ (৩.৫)
- ট্রিক: ৮-বিট ২-এর পরিপূরকে বাম ঘরের মান −128, বাকি ঘর আগের মতো। যোগ করলেই মান।
- উদাহরণ: বইয়ের 25 − 50-এর উত্তর 11100111 = −128 + 64 + 32 + 4 + 2 + 1 = −25।
- টিপস: খাতায় বইয়ের মতো আবার পরিপূরক নিয়ে দেখাবে; ট্রিক দিয়ে মিলিয়ে নেবে।
- কুইজ: 11111011 = ? → −5

### ১৪. যোগ দিয়ে বিয়োগ (৩.৫)
- ট্রিক: বিয়োগ মানে ঋণাত্মকের সাথে যোগ। ৮ বিটের বাইরে যাওয়া নবম বিট বাদ (আট সিটের মাইক্রোবাস)।
- উদাহরণ (বই): 50 − 25 → 00110010 + 11100111 = 1 00011001 → 00011001 = 25
- কুইজ: ৮-বিটে −20 → 11101100

### ১৫. একই ২৭, দুই চেহারা: BCD (৩.৬)
- ট্রিক: BCD-তে প্রতিটা দশমিক অঙ্ক আলাদা ৪ বিট। 27 = (11011)₂, কিন্তু BCD-তে 0010 0111।
- বই: (4578)₁₀ = 0100 0101 0111 1000; 1010–1111 BCD-তে ব্যবহার হয় না।
- কুইজ: BCD 0100 1001 → 49

### ১৬. A থেকে a: শুধু ৩২ যোগ (ASCII, ৩.৬, টেবিল ৩.৪)
- ট্রিক: A = 65, a = 97। বড় হাতের অক্ষরের সাথে 32 যোগ করলে ছোট হাতের; 32 = 2⁵, তাই বদলায় একটাই বিট।
  অঙ্কের ASCII = 48 + অঙ্ক ('0' = 48)।
- কুইজ: B = 66 হলে b = ? → 98

## পরের সিরিজ: লজিক গেট (অধ্যায় ৩-এর দ্বিতীয় ভাগ)
- সিঁড়ির লাইট কোন গেট? (৩.৭.৪, বইয়ের দুই সুইচ: Q = xy + x̄ȳ)
- তিন বন্ধু, দুজন রাজি হলেই ট্যুর (ভোটের সার্কিট xy + yz + zx)
- ডি মরগান: "রেখা ভাঙো, চিহ্ন বদলাও" (দুটো সূত্রই সত্যক সারণিতে মেলানো)
- একটা গেট দিয়েই বাকি সব: NAND (৩.৭.৫)
- ১ + ১ = ১০, এবার সার্কিটে: হাফ অ্যাডার (S = XOR, C = AND)

## মালিকের সিদ্ধান্ত লাগবে
- ক্যালকুলেটরের BASE mode দিয়ে উত্তর মিলিয়ে নেওয়া: শিক্ষার্থীদের কাজে লাগে, কিন্তু মডেলের নাম লাগবে, আর বাটনের
  ধাপ আসল ক্যালকুলেটরে চালিয়ে দেখতে হবে। সৃজনশীলে নিয়ম দেখাতেই হয়, তাই ট্রিকটা শুধু "চেক" হিসেবে বলবে।
